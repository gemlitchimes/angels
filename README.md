# angels — giao diện Google AI Studio

Nền đen ngả tím, chữ trắng font có chân, sao trắng và bướm trắng bay nhẹ, khung chat kính trong, đốm sáng theo chuột, nút bạc và tiếng chuông gió khi bấm.

created by **Poesía of the Gemlit Chimes**

## Cài đặt
1. Mở `chrome://extensions`, bật **Developer mode**.
2. Kéo thả file .zip vào, hoặc giải nén và bấm **Load unpacked** chọn thư mục.
3. Mở/tải lại https://aistudio.google.com (nên đặt Theme = Dark).

Không bật chung với các giao diện AI Studio khác.
